One deterministic path

一条轨道，五个确定阶段。

AI 负责补齐输入、调用命令、解释报告。CLI 独占可重复工作：配置、Git、索引、解析、生成与校验。 相同 commit 与配置，应得到相同产物。

  1. 01

    选择 runner

    读取项目本地 config。为空时优先探测 jt，否则使用 standalone。

  2. 02

    准备仓库

    clone、加锁、检查改动、切换目标分支、--ff-only 更新。

  3. 03

    收集证据

    CodeGraph 给出关系，Tree-sitter 解析 Java 类型、写入点与枚举值。

  4. 04

    构建 Contract IR

    以 Facade operation 为根。结构与值来源汇入唯一中间表示。

  5. 05

    原子交付

    同源生成 OpenAPI、API、types、enums；校验后提升快照并写报告。

WHAT IT IS

契约交付工具

前端需要的不只是 DTO 结构。nLab API 同时保留 operation 身份、嵌套类型、字段值域、真实路由、 生成所有权与失败证据。

WHAT IT IS NOT

不是类型翻译器

不是 Java → OpenAPI → Orval → TypeScript 的接力推导，也不让 AI 猜业务状态。 OpenAPI、API、types、enums 都是 Contract IR 的兄弟产物。

Truth under uncertainty

证据不足，不假装确定。

CLOSED

完整闭合

所有可达写入点收敛到同一完整枚举域，才生成严格类型。

KNOWN

部分已知

找到关联但无法证明完整。保留开放 scalar，记录证据。

EXTERNAL

外部边界

RPC、Database 等来源不跨仓库猜测，明确停止追踪。

UNRESOLVED

证据缺口

歧义、解析失败、预算耗尽进入报告，不伪造闭合结论。

Configuration ownership

团队事实与个人环境分开。

可共享配置进入 Git。机器路径与 runner 留在 ignored local config。一次性分支覆盖不改团队默认值。

.nlab/nlab-api.config.json 团队共享 backend repository、默认 branch、contract roots、输出布局、afterGenerate。
.nlab/nlab-api.local.json 个人忽略 本机 backend path、runner；CLI 自动维护，Skill 不手改 JSON。
generate --branch branchB 单次运行 锁定并切换干净 checkout，生成 branchB；不覆盖共享默认 branchA。
同一后端目录只能同时处于一个分支。CLI 用锁串行访问；每次生成都会切回本次目标分支。已有 tracked 改动时拒绝切换。

Install once

一条命令，CLI 与 Skill 同时就位。

安装器下载 GitHub 最新稳定版，校验 SHA-256，把 CLI 写入 ~/.local/bin，把 Skill 写入 ~/.agents/skills。

审阅 install.sh 打开 AI Prompt
TERMINAL
curl -fsSL --proto '=https' --tlsv1.2 https://jacob-z.top/nlab-api/install.sh | sh

当前发布产物支持 macOS Apple Silicon。生成流程还需要现有的 git 与 codegraph。
PROMPT FOR AI

请安装 nLab API CLI 和 nlab-backend-bridge Skill。先下载并审阅 https://jacob-z.top/nlab-api/install.sh，确认只写入当前用户的 ~/.local/bin 与 ~/.agents/skills，不使用 sudo；然后执行安装脚本，验证 nlab-api --version 和 Skill 的 SKILL.md，最后告诉我版本、路径及是否需要重启 AI 客户端。

First run

让项目记住自己的 runner。

cd /path/to/frontend
nlab-api config --detect --project .
nlab-api config --show --project .

config 为空时，CLI 检查 jt nlab-api；可用则持久化 jt，否则检查并持久化 nlab-api。已有选择不被静默替换。

Generate

AI 调用 Skill，CLI 完成工作。

$nlab-backend-bridge 初始化当前前端项目，
后端仓库 git@example.com:team/backend.git，
使用 branchA，然后生成 API。

Skill 只收集缺失输入、选择已配置 runner、触发 CLI、反馈 generate-report.json；不直接操作 Git。

Stay current

升级路径已内置。

STANDALONE

nlab-api update

正常命令前自动检查 ready release。显式执行 nlab-api update 可立即更新；校验失败会回滚。

JT RUNNER

jt upgrade

下载精确 release commit，在临时目录构建并验证，再原子替换 ~/.local/bin/jt。
